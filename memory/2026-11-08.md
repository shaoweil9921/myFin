## Cron fix: all systemEvent+main jobs converted (20:20 ET)

### Root cause (confirmed)
All three wedged/failing jobs shared **one** shape: `payload.kind: systemEvent` + `sessionTarget: main`. That enqueues into the main session's in-memory event queue (cap 20), which only drains when a turn runs on the exact key `agent:main:main`. The heartbeat job enqueues into that key but its turns execute on `agent:main:main:heartbeat` - it fills a queue it never reads. <!-- project: github.com/shaoweil9921/myFin -->
