## Jarsy Extraction - Playwright Profile Method (SOLVED)

### Problem
Chrome singleton mechanism was blocking `--remote-debugging-port` launches. DPAPI-encrypted cookies from Chrome profile couldn't be used in isolated cron sessions. Profile directory was locked by running Chrome instances.

### Solution: Dedicated Playwright Profile
Created a **dedicated Playwright profile** (`jarsy_profile` in workspace) that the user logs into once manually, and future cron runs reuse it in headless mode.

### Key Scripts

#### `jarsy_manual_login.py` (ONE-TIME SETUP)
- Launches Playwright with `jarsy_profile` directory
- Opens browser, waits for user to log into Jarsy via Google OAuth
- Auto-detects login by watching for "Private Equity" page content
- Saves cookies to the profile directory
- Run once: `python jarsy_manual_login.py`

#### `jarsy_extract.py` (CRON RUN)
- Uses `jarsy_profile` in headless=False mode
- Navigates to PrivateEquity page, clicks Live/Presale tabs
- Parses text content using custom tokenizer
- Saves to `jarsy_presale.json` and `jarsy_live.json`
- Run via cron: `python jarsy_extract.py && python jarsy_save.py`

#### `jarsy_save.py` (CRON RUN)
- Saves JSON tokens to DB: `jarsy_asset` (presale) and `jarsy_asset_live` (live)
- Uses psql for DB insert

### Jarsy Page Structure (from inner_text)
**Live tokens:**
```
[Company Name - Jarsy]
[Symbol]           (e.g. JPOLY)
-                 (separator)
$XXX.XX           (price, optional - may be tab-indented)
Buy / Sell
```

**Presale tokens:**
```
[Company Name - Jarsy (TICKER) Presale]
EARLY ACCESS
[TICKER-PRE]      (e.g. JAXIO-PRE)
-                 (separator)
Buy / Sell
```

**Locking period tokens:**
```
[Company Name - Jarsy]
LOCKING PERIOD
[Symbol]
-                 (separator, may have tab lines before $)
$XXX.XX
Buy / Sell
```

### Parser Logic
- Company name: line contains "- Jarsy"
- Skip tab/whitespace lines after company
- If next line is "EARLY ACCESS" → it's a presale token
- If next line is "LOCKING PERIOD" → it's a locking period token
- Otherwise → normal live token
- Symbol is the next non-empty/non-tab line after the status
- Price: scan forward from symbol for line starting with `$`
- Skip `-` separators before price scanning
