## QuantDinger Reboot Recovery

### What happened
- Docker Desktop was reinstalled (new install, not update)
- Reboot completed
- Docker Desktop service was stopped post-reboot
- QuantDinger's docker-compose needed to be restarted

### Port conflict resolved
- Port 5432 is occupied by the fintech PostgreSQL (running locally on host)
- QuantDinger's own postgres container needed to use 5433 instead
- Fix: set `DB_PORT=127.0.0.1:5433` env var before running docker compose

### How to start QuantDinger (full steps)

1. **Start Docker Desktop**
   ```powershell
   Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
   # Wait ~30s for Docker engine to be ready
   ```

2. **Start QuantDinger with port override**
   ```powershell
   $env:DB_PORT="127.0.0.1:5433"
   docker compose -f C:\QuantDinger\docker-compose.yml up -d
   ```

3. **Wait for services to be healthy**
   ```powershell
   docker compose -f C:\QuantDinger\docker-compose.yml ps
   # All should show "healthy" or "Up"
   ```
